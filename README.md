# Burbot Habitat Suitability Assessment Resources

Data and code for running a decision tree model to classify burbot habitat suitability based on data collected from the River Wissey, Norfolk, UK in 2021.

## Authors

- [@rhpearce](https://github.com/rhpearce)

Based on the research of Pearce et al. (2025).

Pearce, R.H., Sayer, C.D., Chadwick, M.A., Harvey, G.L., Burningham, H., Tosney, J. and Auwerx, J. (2025), Bringing Back the Burbot (Lota lota L.): Assessing Instream and Floodplain Habitat Availability to Support the Reintroduction of a Nationally Extinct Fish. River Res Applic, 41: 1362-1378. https://doi.org/10.1002/rra.4448
